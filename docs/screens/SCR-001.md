# SCR-001: Blapaci dashboard

- **Application:** SISTEMA BLAPACI, version 3.2.0.0
- **Inspection:** Windows UI Automation, read-only; depth 4, maximum 250 nodes.
- **Evidence:** [SCR-001.json](../../evidence/ui/SCR-001.json)

The dashboard exposes separate controls for a material caption and its display
value. The inspected tree includes the caption `EN SILO CEMENTO` and a separate
value control; the supplied legacy screenshot shows numeric aggregate, cement,
water, and additive readings while the PLC is connected.

The database seed maps `ConfigMaq.I1`-`I16` to the captions for
`ctlAdicionale1`-`ctlAdicionale16`. The baseline SQL script defines `dbo.Tags`;
the enabled tag rows and their addresses are installation-specific. The legacy
`Tags.addTypes` enum maps address types 0-4 to MI, MB, OT, FL, and ML. The WinUI
probe translates those to Unitronics MI, MB, Output, MF, and ML operands rather
than reading every tag as MI. `Agua 1` uses the enabled `Agua` tag at MI209.
Read-only dashboard values are read from configured addresses even when
`en = 0`; that flag and any production operation remain unchanged. No live PLC
read was performed as part of the original inspection. A later one-shot
read-only probe, with the original application closed, confirmed
`Cemento1` ML1 = 39760, `Aditivo1` MF10 ≈ 1, `Agua 1` MI209 = 10,
`Fibra1` MF9 = 1, and `Aditivo3` MF19 = 0. These readings match the supplied
original screenshot; `Aditivo3` remains disabled for production operations.
