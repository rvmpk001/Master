# SCR-001: Blapaci dashboard

- **Application:** SISTEMA BLAPACI, version 3.2.0.0
- **Inspection:** Windows UI Automation, read-only; depth 4, maximum 250 nodes.
- **Evidence:** [SCR-001.json](../../evidence/ui/SCR-001.json)

The dashboard exposes separate static controls for a material caption and its
display value. The inspected tree includes the caption `EN SILO CEMENTO` and a
separate `????` value control; the supplied screenshot shows the same pattern
for aggregate, cement, water, and additive readings.

The database seed maps `ConfigMaq.I1`-`I16` to the captions for
`ctlAdicionale1`-`ctlAdicionale16`. It also defines enabled real-time tags
`Adicionale1`-`Adicionale16` in `dbo.Tags`, with MI addresses and multipliers.
The WinUI implementation uses those tags for read-only values. No PLC values
were read from the legacy application during this inspection.
